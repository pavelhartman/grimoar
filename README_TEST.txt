KRVAVÝ GRIMOÁR – MOBILNÍ CHECKPOINT V16

Pro GitHub Pages nahrajte do kořene stejného adresáře/repozitáře:
- index.html
- TEST_MOBILE.html
- celou složku assets

Na telefonu pak otevřete přes adresu GitHub Pages soubor TEST_MOBILE.html.
Nepoužívejte náhled souboru na github.com – GPS a chování webu testujte přes GitHub Pages (https://...github.io/...).

Co zkontrolovat:
1) HUB -> lokace -> zpět bez změny stavu.
2) Havíři: žádné značky na Hrádku; na jiné běžné lokaci ano; po použití už ne; nikdy Ruthardtka.
3) Konšelé: měšec jednou, pak už ne.
4) Pergamen z HUBu + návrat.
5) Ruthardtka: bez bypassu GPS a bez hornických značek; správná GPS vede rovnou k pečeti.
6) Refresh: stav hry zůstane zachován.
7) Pinch zoom na mobilu.

Tento balík je technický checkpoint, ne finální grafická verze.
